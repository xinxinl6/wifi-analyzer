# 2026-04-28 工作日志

## 修复 TabBar 拦截全局点击事件问题（根因）

**问题**：`buildAuroraTabBar()` 的 Stack 设置了 `.width('100%').height('100%')`，覆盖整个屏幕，拦截所有点击事件。

**根因**：Stack 中后添加的组件会覆盖先添加的。TabBar Stack 设置 `100%` 宽高后，会覆盖内容层，导致所有内容层的点击都被 TabBar 拦截。

**修复**：`buildAuroraTabBar()` 移除 `.height('100%')`，高度由内容撑起，只覆盖底部区域。

**涉及文件**：`entry/src/main/ets/pages/Index.ets`

## 修复 @Builder 内点击事件不响应问题

**问题**：`ToolsSection.ets` 的 `@Builder ToolSection` 中，ForEach 循环内的点击事件通过 `this.navigateTool()` 间接调用，导致点击无响应。

**原因**：ArkUI/ArkTS 中 @Builder 内部的方法调用可能存在 `this` 上下文问题。

**修复**：将 `onClick` 中的间接调用改为直接调用 `RouterManager.navigate(item.action as RouteName)`，与 `AuroraDashboard.ets` 的 `AuroraToolsGrid` 保持一致。

**文件**：`entry/src/main/ets/components/ToolsSection.ets`
- 删除 `navigateTool()` 方法
- 修改 `@Builder ToolSection` 中的 `onClick` 直接调用 RouterManager

## XiaoYiHelper ArkTS 语法修复记录（踩坑积累）

- ArkTS 不支持 namespace 内的 `this`，必须用纯函数
- `any`/`unknown` 均不允许，需显式类型
- 对象字面量不能作为类型，需对应显式 class/interface
- `Want.parameters` 需要 `Record<string, Object>` 类型，不支持自定义 interface（除非有索引签名，但索引签名也不允许）
- 解决方案：直接在 `uri` 传参数，不使用 `parameters`
- `UIAbilityContext` 从 `common.UIAbilityContext` 访问，不能直接从 `@kit.AbilityKit` 导入
