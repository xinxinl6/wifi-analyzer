## Toast提示语显示异常修复 (下午)

### 问题描述
Ping测试和路由追踪页面点击时，Toast提示语显示为资源key名（如"err_empty_input"）而非友好文案。

### 根因分析
HAR模块隔离问题：`tools`模块中的页面使用`$r('app.string.xxx').toString()`获取字符串时，只能解析本模块的资源。但由于某些字符串（如验证错误提示）之前只添加到了`entry`模块的string.json中，没有同步到`tools`模块，导致找不到资源时显示key名。

### 修复方案
1. 在每个需要获取字符串值的页面组件中添加`getString()`辅助方法：
```typescript
private getString(str: Resource): string {
  try {
    return getContext(this).resourceManager.getStringSync(str.id)
  } catch {
    return ''
  }
}
```

2. 将所有`$r('app.string.xxx').toString()`调用改为`this.getString($r('app.string.xxx'))`

3. 补充`tools`模块缺失的字符串资源到`tools/src/main/resources/base/element/string.json`
