# 2026-05-13 工作记录

## 修复：深色/浅色模式切换监听

### 问题
用户在真机上从深色模式切换到浅色模式时，应用文字几乎看不见（白色文字在白色背景上）。

### 根因
`Index.ets` 中 `isDarkMode` 只在 `aboutToAppear()` 中读取一次系统配置，没有监听系统颜色模式变化。

### 修复内容
1. **Index.ets** - 添加 `onConfigurationUpdate()` 生命周期回调：
   - 监听系统 `Configuration.colorMode` 变化
   - 实时更新 `this.isDarkMode` 和 `AppStorage`
   - 导入 `Configuration` 类型

```typescript
// 监听系统深色/浅色模式切换
onConfigurationUpdate(newConfig: Configuration): void {
  const newColorMode = newConfig.colorMode
  const isDark = (newColorMode === ConfigurationConstant.ColorMode.COLOR_MODE_DARK)
  if (this.isDarkMode !== isDark) {
    hilog.info(DOMAIN, 'testTag', '%{public}s', '[Index] System color mode changed: isDarkMode=' + isDark)
    this.isDarkMode = isDark
    AppStorage.setOrCreate('isDarkMode', isDark)
  }
}
```

2. **导入更新**：
   ```typescript
   import { common, ConfigurationConstant, Configuration } from '@kit.AbilityKit'
   ```

### 验证
- 颜色系统已正确配置浅色模式文字色：
  - `COLOR_TEXT_LIGHT_PRIMARY = '#1E293B'` (对比度 ~12:1)
  - `COLOR_TEXT_LIGHT_SECONDARY = '#475569'` (对比度 ~5.5:1)
  - `COLOR_TEXT_LIGHT_TERTIARY = '#64748B'` (对比度 ~4.5:1)
- 所有 Aurora 组件（AuroraConnectionCard、AuroraNetworkGrid、AuroraToolsGrid）都使用 `isDarkMode` 条件渲染

### 修复2：@Prop 改为 @Consume（2026-05-13 09:15）

**问题**：`@Prop` 装饰器在父组件状态变化时不会自动同步给子组件。

**修复**：将所有 Aurora 组件中的 `isDarkMode` 从 `@Prop` 改为 `@Consume('isDarkMode')`：

1. **AuroraConnectionCard** - `@Prop isDarkMode` → `@Consume('isDarkMode') isDarkMode`
2. **AuroraNetworkGrid** - `@Prop isDarkMode` → `@Consume('isDarkMode') isDarkMode`
3. **AuroraToolsGrid** - `@Prop isDarkMode` → `@Consume('isDarkMode') isDarkMode`
4. **AuroraDashboard** - `@Prop isDarkMode` → `@Consume('isDarkMode') isDarkMode`
5. **Index.ets** - 移除 `AuroraDashboard({ isDarkMode: this.isDarkMode })` 参数传递

**原理**：`@Consume` 会自动从祖先组件的 `@Provide('isDarkMode')` 或 AppStorage 中消费状态，状态变化时自动触发子组件重渲染。

### 修复4：根因修复 — EntryAbility 监听 + 全局 @StorageLink（2026-05-13 09:21）

**根本原因**：
1. `onConfigurationUpdate` 必须在 `UIAbility`（EntryAbility）中实现，在 `@Entry @Component` struct 中写无效
2. `@StorageLink` 和 `@Provide` 不能叠加装饰同一变量（ArkTS 编译器报错）

**正确方案**：
- `EntryAbility.onCreate` → 初始化 `AppStorage.setOrCreate('isDarkMode', isDark)`
- `EntryAbility.onConfigurationUpdate` → 系统主题切换时更新 AppStorage
- 所有 UI 组件（Index, AuroraDashboard 等）→ `@StorageLink('isDarkMode')` 直接响应 AppStorage 变化
- 不再使用 `@Provide/@Consume` 传递 `isDarkMode`

**修改文件**：
- `entry/src/main/ets/entryability/EntryAbility.ets` — 添加 `onConfigurationUpdate` + `onCreate` 初始化
- `entry/src/main/ets/pages/Index.ets` — `@Provide` → `@StorageLink('isDarkMode')`，移除 `onConfigurationUpdate`
- `entry/src/main/ets/components/AuroraDashboard.ets` — 4处 `@Consume` → `@StorageLink`
- `entry/src/main/ets/components/SpeedTestSection, ToolsSection, WifiListSection, AboutPage, ContentPage, PingTestPage` — 同上
- `tools/src/main/ets/` 下全部子页面 11 个文件 — `@Consume` → `@StorageLink`
- `entry/src/main/ets/components/AuroraGlassComponents.ets` — 信号条空格色 `rgba(255,255,255,0.2)` → `rgba(148,163,184,0.3)`
