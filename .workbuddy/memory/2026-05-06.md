## WebView 搜索从 Bing 改为百度移动版 (2026-05-06 下午)

### 问题
WebView 中的 Bing 搜索页面自带麦克风语音搜索图标，用户希望移除。

### 解决方案
将 XiaoYiHelper 中的搜索 URL 从 Bing 改为百度移动版：
- `getAIAnalysisUrl()`: `https://www.bing.com/search?q=` → `https://m.baidu.com/s?word=`
- `getDeepSeekAnalysisUrl()`: 同上
