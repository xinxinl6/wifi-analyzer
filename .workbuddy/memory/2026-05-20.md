## 编译错误修复（177→0 期望）

大文件拆分后产生177个编译错误，分类修复：

### 修复类别
1. **ArkTS 语法违规**（PingStatsHelper 50+ errors, TabAnimationHelper 16+ errors）
   - `static interface` → 接口必须在类外声明
   - 对象字面量返回类型 → 提取为命名接口（Phase1States, ChartDataResult, ChannelComputeResult 等）
   - `any` → 使用显式类型
   - `curves.InterpolatingSpring` → `curves.ICurve`

2. **缺失 design-system 导出**（COLOR_GLASS_SKY_DIVIDER/COLOR_SKY_BLUE_ACTIVE/GLASS_BLUR_10/AnimationCurve 不存在）
   - COLOR_GLASS_SKY_DIVIDER → COLOR_SKY_BLUE_DIVIDER
   - COLOR_SKY_BLUE_ACTIVE → COLOR_GLASS_SKY_ACTIVE
   - GLASS_BLUR_10 → GLASS_BLUR_MD
   - AnimationCurve → 删除导入，用内置 Curve

3. **缺失导入/属性**（各子组件缺少常量/类型导入）
   - COLOR_PURPLE/FONT_SIZE_SM/FONT_SIZE_MD/SPACE_SM/SPACE_LG/FONT_WEIGHT_BOLD/COLOR_SUCCESS 等

4. **类型不匹配**
   - PingResultView 本地 PingResult 缺 host/ttl → 直接用 PingEngine 的 PingResult
   - PortScanResult status 'error' 不在联合类型 → 映射为 'unknown'
   - PoeStandard 缺 current/pins → 补全默认值
   - RoamTestSummary 缺 avgRssi → 补全默认值

5. **@ObjectLink/@StorageLink 误用**
   - PulseIndicator 加 @Observed 以支持 @ObjectLink
   - PrivacyDialog/PermissionDialog 的 @StorageLink 不允许外部初始化 → 移除传参

6. **属性名冲突**
   - WifiScanButton.onClick 与 CustomComponent.onClick 冲突 → 改名 onTap

7. **其他**
   - DnsIdleView 删除不存在的 DnsServerDisplay 导入
   - DnsResultView 移除不存在的 isQuerying/QueryingState 引用
   - WifiListItem bare `signal` → `this.signal`
   - SpeedTestSection `context as object` → `context as common.UIAbilityContext`
   - AuroraDashboard/AIAnalysisPanel 回调返回类型 → 提取 WifiStateCallbackResult 接口

### ArkTS 踩坑新增
- **static interface 禁止** — ArkTS 不支持在 class 内声明 static interface，必须移到类外
- **对象字面量类型声明禁止** — 返回类型不能用 `{ a: number, b: string }` 内联，必须提取为 interface
- **@StorageLink 禁止外部初始化** — 父组件不能给子组件的 @StorageLink 属性赋值
- **属性名不能与内置冲突** — 组件自定义属性如 onClick 会与 CustomComponent.onClick 冲突

## HAR→HSP 评估

### ArkTS 踩坑新增
- **@Consume 不需初始值** — @Consume 由 @Provide 注入，interface 类型不能 new，对象字面量初始化也不合法
- **import 语句不能断裂** — 两个 import 不能合并写（缺 `import {` 开头会被当作逗号表达式）
- **@ObjectLink 只接受 @State 传递** — 普通私有属性不能传给 @ObjectLink；替代方案：用 @Prop 传所需的具体值

## 运行时修复：历史趋势弹窗空白

**问题**：点击 Ping 测试页的「历史趋势」功能卡片，弹窗只显示底部一条灰色条，内容空白。

**修复**（`PingTestPage.ets`）：
- 将 `HistoryModal` 的 `if` 块从主内容 `Column()` 内部移出，放到根 `Stack()` 里与主内容 `Column()` 平级
- 这样 `HistoryModal` 的 `Stack` 才能以全屏覆盖层方式正确工作

**附带修复**（`PingHistoryModal.ets`）：
- 给 `HistoryModal` 根 `Stack` 补上 `.width('100%').height('100%')`，确保遮罩层和卡片百分比尺寸正确计算
