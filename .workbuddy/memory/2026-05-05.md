## 编译错误修复 (2026-05-05 上午 10:46)

### `NetConnection.off` 方法不存在
- **问题**：`DnsLookupEngine.ets` 中的 `lookupOnNetwork()` 方法使用了 `conn.off('netAvailable')` 和 `conn.off('netUnavailable')`
- **原因**：当前 SDK 版本中 `NetConnection` 类型没有 `off` 方法
- **解决**：移除这些 `off` 调用，超时后 Promise 被 reject，事件处理器自然不会再被触发

### 3. DNS 查询引擎升级到 Network Kit API v23

根据用户提供的 HarmonyOS Network Kit API v23 文档，升级了 `DnsLookupEngine.ets`：

**新功能支持：**
1. **Promise 风格 API** - 将回调风格的 `connection.getAddressesByName(name, callback)` 改为 Promise 风格的 `connection.getAddressesByName(name).then()`
2. **中文域名支持** - 使用 `connection.getDnsAscii()` 自动将中文域名转换为 ASCII（Punycode）后再解析
3. **IPv4/IPv6 指定解析** - 使用 `connection.getAddressesByNameWithOptions(name, { family: FAMILY_TYPE_IPV4/IPV6 })` 可指定只解析 IPv4 或 IPv6 地址
4. **指定网络连接解析** - 可在特定网络（Wi-Fi 或蜂窝）上解析（`connection.createNetConnection()` + `netAvailable` 事件）
5. **IPv6 自动识别** - 智能判断地址类型，地址含 `:` 判定为 IPv6 (AAAA 记录)

**代码变更：**
- `DnsLookupEngine.ets`:
  - 新增 `IpFamily` 类型：`'IPv4' | 'IPv6' | 'All'`
  - `DnsLookupConfig` 新增 `family` 和 `networkType` 字段
  - 新增 `resolveAddressesAll()` - Promise 风格获取所有地址
  - 新增 `resolveAddressesByFamily()` - 按 IP 族解析
  - 新增 `lookupWithDefaultNet()` - 在默认网络上解析
  - 新增 `lookupOnNetwork()` - 在指定网络上解析
  - `lookup()` 主方法整合中文域名转换和 IP 族筛选

- `DnsLookupPage.ets`:
  - 新增 `IpFamilySection()` Builder - UI 选择器支持"全部/IPv4/IPv6"
  - 新增 `ipFamilyIndex` 状态和 `ipFamilyOptions` 数组
  - `doQuery()` 传递 `config.family` 参数

- `string.json` 新增：`chinese_domain_support`, `chinese_domain_desc`, `ip_family_all`, `ip_family_ipv4`, `ip_family_ipv6`, `ip_family_label`

**SDK 路径发现：**

- OpenHarmony SDK: `C:/Users/xinxin/AppData/Local/OpenHarmony/Sdk` (有 23 等版本)
